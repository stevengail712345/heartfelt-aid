# Heartfelt Aid

Help me set up a charity organization with fund raising attached to it were people from all over the world can donate money to help others with real time touching stories of people who are in need of financial assistance because of one reason or the other. I want pictures attached to each story and I also want testimonies of people and families who have received help through the organization. Some of the story should carry the particular amount needed to solve the problem while some should carry a fraction of the amount needed because they already have part of it but just need some more for it to be complete. Some of the cases for fundraising should have part of the money already donated but need some more for it to be completed and the currency should be in usd
